# SuperStore Data Analysis Project

## Objective
To clean, analyze, and visualize sales data using Python.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Steps Performed
- Data cleaning
- Removing duplicates
- Handling missing values
- Exploratory Data Analysis (EDA)
- Data visualization

## Key Insights
- Sales patterns identified across categories
- Profit variation across regions
- Monthly trends analyzed

## Conclusion
This project demonstrates end-to-end data analysis workflow using Python.
